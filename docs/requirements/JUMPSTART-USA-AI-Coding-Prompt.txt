JUMPSTART USA AI Coding Prompt
You are a senior full-stack software architect and production software engineer.

Build a complete web-based operations management platform for JUMPSTART USA, a nationwide nonprofit prison re-entry ministry. The application must manage inside prison programming, outside re-entry programming, transitional housing, participants, volunteers, donors, vendors, employers, vehicles, case management services, fundraising, events, and ministry operations.

This should be built as a professional, production-ready line-of-business application suitable for a national nonprofit organization.

PROJECT NAME
JUMPSTART USA Operations Management Platform

PRIMARY GOAL
Create one centralized application to manage all operations of a nationwide nonprofit prison re-entry ministry.

The system must support:
- Inside prison programming
- Outside prison re-entry programming
- Transitional housing
- Participant case management
- Volunteer management
- Institution management
- Donor and vendor CRM
- Fundraising campaigns
- Events
- Employer tracking
- Employment history
- Ministry vehicle tracking
- Vehicle maintenance records
- Reporting and dashboards

TARGET USERS
The application should support multiple user roles:

1. System Administrator
   - Full access to all modules
   - User management
   - Role and permission management
   - System settings

2. Executive Leadership
   - View organization-wide dashboards
   - View reports
   - Access donor, campaign, participant, and program performance data

3. Inside Program Staff
   - Manage prison institutions
   - Manage inside classes
   - Track class participants
   - Track class completion status and assessments

4. Outside Program Staff / Case Managers
   - Manage outside participants
   - Track onboarding
   - Track case management services
   - Manage transitional housing enrollment
   - Track treatment classes, life skills classes, soft skills classes, Bible studies, and support services

5. Housing Staff
   - Manage transitional homes
   - Track resident enrollment
   - Track move-in and move-out dates
   - Track reasons for leaving
   - Track completion assessments

6. Volunteer Coordinator
   - Manage volunteers
   - Track volunteer training status
   - Track volunteer assignments
   - Track inside and outside class service roles

7. Development / Fundraising Staff
   - Manage donors
   - Manage vendors
   - Track donations
   - Manage fundraising campaigns
   - Manage events

8. Employment Coordinator
   - Manage employers
   - Track participant employment history
   - Track employment status and employer relationships

9. Transportation / Fleet Manager
   - Manage ministry vehicles
   - Track vehicle information
   - Track maintenance records

RECOMMENDED TECHNOLOGY STACK
Use a modern, maintainable full-stack architecture.

Preferred stack:
- Frontend: React with TypeScript
- Backend: Node.js with Express or NestJS
- Database: PostgreSQL
- ORM: Prisma
- Authentication: Role-based authentication using JWT or session-based auth
- UI Framework: Tailwind CSS with a clean admin dashboard design
- Forms: React Hook Form with validation
- Validation: Zod
- Charts/Dashboards: Recharts or similar
- File Uploads: Support document attachments in future-ready structure
- Deployment-ready: Docker-compatible structure
- Testing: Include unit and integration test structure

If using another stack, maintain the same architecture quality and feature completeness.
